# Research share vs. undergraduate coverage of four AI-era hardware topics in ECE

Data and code for:
F. Gül, "Mapping AI-Hardware Topics in the Electrical and Computer Engineering
Curriculum: A Bibliometric and Course-Catalogue Analysis and a Data-Informed
Modular Track," *IEEE Transactions on Education* (under review).

Every number, table and figure in the manuscript and its Supplementary Material
is regenerated by the scripts below from the files in `data/`.

## Pipeline

| Step | Script | Output |
|---|---|---|
| 17 | `scripts/17_harvest_corpus.py` | all journal articles of 13 IEEE journals, 2015–2025, from Crossref (large; written outside the repository) |
| 18 | `scripts/18_classify_corpus.py` | `data/pool_yearly.csv`, `data/wave_matches.csv`, `data/wave_yearly.csv`, `data/nearmiss_pool_sizes.json` (`--sample` regenerates the validation samples; do not use it on the coded files) |
| 19 | `scripts/19_openalex_robustness.py` | `data/openalex_title_abstract_yearly.csv` |
| 20 | `scripts/20_bib_indicators.py` | `data/bib_summary.csv`, `data/bib_windows.csv`, `manuscript/numbers_bib.tex` |
| 21 | `scripts/21_make_fig1_v2.py` | `figures/fig1_research_trends.*` |
| 22 | `scripts/22_build_bib.py` | `manuscript/refs.bib` (from Crossref) |
| 23 | `scripts/23_match_catalogue_v2.py` | `data/course_candidates.csv` (manual codes are preserved on re-run) |
| 24 | `scripts/24_catalogue_indicators.py` | `data/coverage_*.csv`, `manuscript/numbers_cat.tex`, `figures/fig2_coverage.*`, `figures/fig3_alignment.*` |
| 25 | `scripts/25_topic_terms.py` | `data/topic_terms.csv`, `manuscript/numbers_topics.tex` |
| 26 | `scripts/26_build_si.py` | `supplementary/SI.tex` |

Catalogue acquisition scripts (one per programme, run on 2 November 2026) are in
`scripts/catalog_extract/`; the rebuilt catalogues are in `data/catalog_v2/`
(one CSV per programme, `coverage_audit.csv`, and a method note `README.md`).

## Data

* `data/corpus_titles.csv.gz` — DOI, year, journal and title of all 167,269
  harvested records (before removal of non-research items).
* `data/wave_definitions_v2.json` — final classification rules and their
  revision log.
* `data/validation_*.csv` — manually coded validation samples (rounds 2 and 3;
  round 3 is the held-out estimate).
* `data/course_candidates.csv` — every candidate course with its manual code
  (dedicated / partial / false) and justification.

## Running

Run every script from the repository root. Step 17 downloads the corpus to
`$EDU01_RUN_OUT/corpus` (default `~/run_out/EDU01`, ~200 MB); all later steps
use the files already in `data/`, so the analysis can be reproduced without
re-downloading. The catalogue scripts in `scripts/catalog_extract/` write raw
pages to `raw/` and structured CSVs to `data/catalog_v2/`; live catalogues
change, so re-running them yields the current, not the November 2026, state.
Figures use the bundled style file `scripts/pro_style.py`.

## Requirements

Python ≥ 3.10 with `requests`, `numpy`, `scipy`, `matplotlib`; a TeX
distribution with `IEEEtran` for the manuscript.
